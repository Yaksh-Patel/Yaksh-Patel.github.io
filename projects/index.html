02

AI Lab

Pass-time pet projects, built to find the edges of what AI coding tools can do.

I didn't write this code — AI tools did, and I directed them. I brought the idea, the product decisions, the architecture calls, and the review loop: deciding what to build, catching where the model got it wrong, and pushing back until the result was something I'd actually keep installed. The typing was the model's; the judgement was mine.

I ship them because the interesting artifact isn't the app — it's what the process reveals about where AI-assisted development genuinely works today, and where it still needs a human holding the wheel. My read so far: these tools produce competent code fast, and nearly all the remaining leverage is in knowing which competent-looking thing is going to fail in the real world. That gap is worth understanding before it reshapes how software gets built.
